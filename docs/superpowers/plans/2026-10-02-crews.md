# Crews Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Crews: up to 8 friends share a daily tower, reached from a glass
button top left of Wins, built to feel like Messages, with everyone's living
heads and a cramped bubble.

**Architecture:** A `SocialStore` (`@MainActor @Observable`) beside SwiftData
owns crews, today's shared wins, the outbox and the sticky choice, and talks
to a `CrewCloud` protocol. `CloudKitCrewCloud` is the real one (one zone and
`CKShare` per crew); `FakeCrewCloud` backs every test and the simulator seeds.
The crew tower reuses the tower's packer, block, drop and dance through a
value seam on `PlacedBlock`; the head system is generalised from one head to N.

**Tech Stack:** Swift 6, SwiftUI (iOS 26), CloudKit, ContactsUI, MessageUI,
UserNotifications + a Notification Service Extension, SensitiveContentAnalysis,
DeclaredAgeRange, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-02-crews-design.md`

## Global Constraints

- Up to **8 members including you**; up to **5 crews** per person; enforced in `SocialStore`, never in a view.
- Friends' wins are **never** `Habit`/`HabitLog` rows. `SocialStore` has no `ModelContext` in its interface.
- `SharedWin` record keys are exactly: `winID senderProfileID crewDay title colour icon blockSize photo cropX cropY createdAt updatedAt`.
- No note, caption, place, coordinates, accuracy, habit id, plan item or mood in any record.
- Photos sent are 1080px long edge, re-encoded, no `{Exif}`, no `{GPS}`. 13 to 15: no photo at all.
- The crew day is `yyyy-MM-dd` in the crew's `timeZoneIdentifier` (the creator's), via `Calendar`, never string arithmetic.
- Everything behind `CrewsFlag` (off by default; `-strataCrews 1`). Off: no button, no checkboxes, no subscription, no network, no zone.
- No long dash (— or –) in anything a person reads. No surveillance words ("watching", "tracking", "active now", "see what your friends are doing").
- Motion only through `GridConstants` tokens; haptics only through `HapticsEngine`.
- `docs/design.md` LOCKED rows hold: white block labels, radius 8 / 12 merged, falls have no ease, ink accent, 15pt floor, bubble left of Plan on Wins.
- Never `try?` a CloudKit write or delete: log, retry through the outbox, surface on the block's back.
- Stage only your own paths: `git commit -- <paths>`; new files `git add <path>` by name. Never `-a`, never `add -A`.
- Build: `xcodebuild build -project Strata.xcodeproj -scheme Strata -destination 'id=CDC76075-642B-4454-A7A5-A4FC76871E41' -derivedDataPath /tmp/dd-e`
- Test: `xcodebuild test -project Strata.xcodeproj -scheme Strata -testPlan Strata -destination 'id=49C2FF40-7922-4F10-A225-6C7182CFD7C6' -derivedDataPath /tmp/dd-f-test` (add `-only-testing:StrataTests/<Suite>` while iterating).
- The project uses synchronized folder groups: a new `.swift` file under `Strata/` or `StrataTests/` is in the target with no pbxproj edit.

### Task 1: The crew domain, records and the store on a fake cloud

**Files:**
- Create: `Strata/Social/CrewModels.swift`, `CrewDay.swift`, `CrewRecords.swift`, `CrewCloud.swift`, `FakeCrewCloud.swift`, `SocialStore.swift`, `CrewOutbox.swift`, `CrewChoice.swift`, `CrewsFlag.swift`
- Test: `StrataTests/CrewStoreTests.swift`, `StrataTests/CrewRecordTests.swift`

**Interfaces:**
- Produces:
  - `struct CrewID: Hashable, Codable, Sendable { let rawValue: String }` (the zone name, `"crew-" + UUID`)
  - `struct Crew: Identifiable, Codable, Equatable, Sendable { id: CrewID; name: String; ownerProfileID: UUID; timeZoneIdentifier: String; createdAt: Date; photo: URL?; members: [CrewMember] }` with `var displayName: String` ("Sam, Ana and Leo" when unnamed) and `var timeZone: TimeZone`
  - `struct CrewMember: Identifiable, Codable, Equatable, Sendable { profileID: UUID; firstName: String; head: URL?; joinedAt: Date }`
  - `struct SharedWin: Identifiable, Codable, Equatable, Sendable { winID: UUID; crewID: CrewID; senderProfileID: UUID; crewDay: String; title: String; colour: HabitCategory; icon: HabitCategory; blockSize: BlockSize; photo: URL?; cropX: Double?; cropY: Double?; createdAt: Date; updatedAt: Date }`
  - `enum CrewError: Error, Equatable { case tooManyCrews, crewFull, flagOff, notOwner, notSignedIn }`
  - `enum CrewCaps { static let members = 8; static let crews = 5 }`
  - `enum CrewDay { static func string(for: Date, in: TimeZone) -> String }`
  - `enum CrewValue: Equatable, Sendable { case string(String), date(Date), double(Double), int(Int), uuid(UUID), asset(URL) }`, `typealias RecordFields = [String: CrewValue]`
  - `enum CrewRecords { static let sharedWinKeys: Set<String>; static func fields(_: SharedWin) -> RecordFields; static func sharedWin(_: RecordFields, crew: CrewID) -> SharedWin?` (and the same pair for `Crew` and `CrewMember`)
  - `@MainActor protocol CrewCloud: AnyObject` (below)
  - `@MainActor @Observable final class SocialStore` with `static let shared`, `init(cloud:defaults:directory:)`, `crews`, `wins(in:) -> [SharedWin]`, `unread: Set<CrewID>`, `createCrew(name:) async throws -> (Crew, URL)`, `inviteURL(for:) async throws -> URL`, `accept(_ invite: CrewInvite) async throws -> Crew`, `post(_ win: OwnWin, to: Set<CrewID>) async`, `withdraw(winID:from:) async`, `deleteEverywhere(winID:) async`, `removePhotoEverywhere(winID:) async`, `rename(_:to:) async throws`, `setPhoto(_:data:) async throws`, `leave(_:) async throws`, `end(_:) async throws`, `remove(member:from:) async throws`, `refresh() async`, `flush() async`, `prune(now:)`, `markSeen(_:)`, `pendingCrews(for winID: UUID) -> Set<CrewID>`
  - `struct OwnWin: Sendable { winID: UUID; title: String; colour: HabitCategory; icon: HabitCategory; blockSize: BlockSize; photoJPEG: Data?; cropX: Double?; cropY: Double?; createdAt: Date; updatedAt: Date }` (built from a `HabitLog` by the callers in Task 8, so this file imports no SwiftData)
  - `enum CrewChoice { static func load(_: UserDefaults) -> Set<CrewID>; static func save(_: Set<CrewID>, _: UserDefaults); static func forget(_: CrewID, _: UserDefaults) }`
  - `enum CrewsFlag { static var isOn: Bool }` (`UserDefaults` `crewsEnabled`, or `-strataCrews 1`)

```swift
@MainActor
protocol CrewCloud: AnyObject {
    var myProfileID: UUID { get }
    func createZone(_ crew: Crew) async throws -> URL          // returns the share URL
    func shareURL(for crew: CrewID) async throws -> URL
    func accept(_ invite: CrewInvite) async throws -> CrewID
    func fetchCrews() async throws -> [Crew]
    func fetchWins(in crew: CrewID) async throws -> [SharedWin]
    func save(_ fields: RecordFields, type: CrewRecordType, name: String, in crew: CrewID) async throws
    func delete(type: CrewRecordType, name: String, in crew: CrewID) async throws
    func leave(_ crew: CrewID) async throws
    func endCrew(_ crew: CrewID) async throws
    func removeParticipant(_ profileID: UUID, from crew: CrewID) async throws
}
enum CrewRecordType: String, Sendable { case crew = "Crew", member = "Member", sharedWin = "SharedWin" }
struct CrewInvite: Sendable { let url: URL; let metadata: Any? }   // CKShare.Metadata on device
```
